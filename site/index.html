En 3 étapesIn 3 steps

  1. InstalleInstall

    Clique sur le bouton de ton système. Ouvre le fichier téléchargé (dans Téléchargements) en double-cliquant dessus, puis suis l'installateur.

    Click the button for your system. Open the downloaded file (in Downloads) by double-clicking it, then follow the installer.

  2. Colle un lienPaste a link

    Dans ALLTube, colle le lien avec CTRL + V, choisis un format (par exemple MP3 HQ pour la musique) et clique sur OK.

    In ALLTube, paste the link with CTRL + V, pick a format (for example MP3 HQ for music) and click OK.

  3. Retrouve tes fichiersFind your files

    Ouvre l'Explorateur de fichiers, puis Téléchargements, puis le dossier ALLTube. Tout est là.

    Open File Explorer, then Downloads, then the ALLTube folder. Everything is there.
