# ALLTube 1.0.0 (November 2026)

**First public version / Première version publique.**

## English

ALLTube is a free, open source desktop app (MIT) that downloads videos and music from the sites supported by yt-dlp. No account, no daily limit, no telemetry.

**Highlights**
- 14 formats: MP4 SD / HD / FHD / 2K, 3GP, FLV, custom codecs, MP3 (128 / 192 / 320 kbps), M4A, OGG, FLAC, WAV
- Video and audio cutting (fast or precise)
- Subtitles, other audio tracks, notifications, several downloads at once, dark and light themes, browser cookies
- Interface in French, English and Chinese (Mandarin)
- Security by design: no shell, validated inputs, strict content security policy

**Install (Windows 11)**: download `ALLTube_1.0.0_x64-setup.exe` below and double-click it. If Windows shows "Windows protected your PC", click **More info** then **Run anyway** (the installer is not code-signed yet). Your files go to `Downloads > ALLTube`.

**Verify the file**: compare `Get-FileHash .\ALLTube_1.0.0_x64-setup.exe -Algorithm SHA256` with `SHA256SUMS.txt`.

**Known issue**: a red error can appear even though the file was saved correctly. Check the `ALLTube` folder in Downloads. See [CHANGELOG](https://github.com/madjeek-web/alltube/blob/main/CHANGELOG.md).

macOS and Linux installers are planned (see the [roadmap](https://github.com/madjeek-web/alltube/blob/main/ROADMAP.md)).

## Français

ALLTube est un logiciel de bureau gratuit et open source (MIT) qui télécharge des vidéos et de la musique depuis les sites pris en charge par yt-dlp. Sans compte, sans limite par jour, sans télémétrie.

**Points forts**
- 14 formats : MP4 SD / HD / FHD / 2K, 3GP, FLV, codecs personnalisés, MP3 (128 / 192 / 320 kbps), M4A, OGG, FLAC, WAV
- Découpe de vidéos et de sons (rapide ou précise)
- Sous-titres, autres pistes audio, notifications, plusieurs téléchargements en même temps, thèmes sombre et clair, cookies du navigateur
- Interface en français, anglais et chinois (mandarin)
- Sécurité dès la conception : aucun shell, entrées validées, politique de sécurité stricte

**Installer (Windows 11)** : télécharge `ALLTube_1.0.0_x64-setup.exe` ci-dessous et double-clique dessus. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires** puis **Exécuter quand même** (l'installateur n'est pas encore signé). Tes fichiers vont dans `Téléchargements > ALLTube`.

**Vérifier le fichier** : compare `Get-FileHash .\ALLTube_1.0.0_x64-setup.exe -Algorithm SHA256` avec `SHA256SUMS.txt`.

**Problème connu** : une erreur rouge peut s'afficher alors que le fichier est bien enregistré. Regarde le dossier `ALLTube` dans Téléchargements. Voir le [CHANGELOG](https://github.com/madjeek-web/alltube/blob/main/CHANGELOG.md).

Les installateurs macOS et Linux sont prévus (voir la [feuille de route](https://github.com/madjeek-web/alltube/blob/main/ROADMAP.md)).
